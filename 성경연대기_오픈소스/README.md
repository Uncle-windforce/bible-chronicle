# 성경 연대기 (HOON reader · Bible Chronicle)

성경의 족보·이야기·전쟁사·나라별·지도·문화·인물 생애·왕·제국·세계사를 한 연표로 보는 **단일 HTML 파일** 앱입니다. 설치 없이 파일을 브라우저로 열면 됩니다. 인터넷 연결 없이도 연대기 화면은 모두 동작합니다.

## 라이선스
- 직접 만든 코드와 글·그림: **MIT License** (`LICENSE`)
- 파일 안에 포함된 제3자 오픈소스(PDF.js 등): 각자의 라이선스 (`THIRD_PARTY_NOTICES.md`, 앱 안 ‘오픈소스 라이선스’ 화면)

## 성경 본문에 대해 (중요)
- 이 저장소/파일에는 **성경 전체 본문이 들어 있지 않습니다**(짧은 개역한글판 인용은 아래 ‘성경 구절 인용 표기’ 참고). 개역개정·새번역 등 대부분의 한국어 번역본은 저작권이 있어 포함하지 않았고, 포함해서도 안 됩니다.
- 구절 본문을 보려면 사용자가 **자기가 가진 성경 PDF**를 `📖 성경 불러오기`로 불러옵니다. 파일은 사용자의 브라우저 안에만 저장되며 어디로도 전송되지 않습니다.
- 저작권이 풀린 번역(예: 영어 KJV, 개역한글 등 권리 상태는 직접 확인)의 PDF를 쓰는 것도 좋습니다. 권리 확인은 사용자 책임입니다.

## 성경 구절 인용 표기
- 성경 **전체 본문은 들어 있지 않아요.** 구절 본문은 사용자가 가진 성경 PDF(개역개정·흠정역 등 어떤 번역본이든)를 앱에 불러와 봐요. 성경 PDF·텍스트 파일을 저장소나 배포 파일에 넣지 마세요.
- 카드 속 **큰따옴표(“ ”) 안의 성경 말씀(약 200곳)은 모두 개역한글판**(대한성서공회 1961, 저작재산권 보호기간 2011년 말 만료) 원문 그대로이고, 구절 주소를 함께 적었어요. 줄인 곳은 ‘…’로 표시했어요. 작은따옴표(‘ ’)는 풀어 쓴 요약이에요.
- 인용을 새로 넣을 때도 **개역한글판 원문만** 쓰세요. 개역개정판 등 저작권이 있는 번역의 문장은 넣지 마세요.
- 개역한글판 원문 대조에는 공개 자료(github.com/thiagobodruk/bible 의 ko_krv)를 썼어요.
## 내용 출처와 한계
- 연대는 기본이 **어셔 연대(BC 4004 창조 등)**이고, ‘일반 학설’로 바꿔 볼 수 있습니다. 두 연대 모두 학자마다 다르며 **대략값**입니다. 교재·목사님과 함께 확인하세요.
- 지도의 경계와 위치는 이해를 돕는 **약식 그림**이며 직접 새로 그렸습니다. 위치가 불확실한 곳은 대략의 자리입니다.
- ‘성경 밖 기록’이라고 적은 내용은 성경 본문에 없는 역사 기록입니다.

## 외부 연결(선택 기능)
기본 화면은 외부 서버에 연결하지 않습니다. 일부 부가 기능(영어 사전 조회, 책 표지 검색, 글꼴 등)을 쓰면 해당 서비스(dictionaryapi.dev, Open Library, Google Fonts 등)에 요청이 나갈 수 있습니다.
